IB3Pad Menu screens

What changes screen by screen
Everything else follows the Menus sheet

Hub (Siris / Isa)

+Move between Items, Supplies, Skills, Customize, Goals and the gear
LBRBSwitch Siris / Isa
YOpen the gear menu

Items

+Up / down scrolls items; left / right changes item type
ABuy or equip (the cursor waits on the button)
LBRBALL / INVENTORY / STORE
LTRTItems / Gem Bag

Gem Bag

+Move over the gem grid and the item's sockets
APick a gem up; A again drops it
BPut the held gem back
YSell the gem    LT back to items

Supplies

+Scroll the list
AUse (or the single centred button on keys and ingredients)
YBuy

Skills

+Up / down picks a stat row; left / right walks its skills
Y☰Accept the points
BCancel the points    X reset all
LBRBSkills / Stats

Goals

+Row to row, cursor on COLLECT; scrolls at the ends
ACollect

Customize

+Side bar and its sub-menu rows, scrolling the sub-menu
R3Hold and move the right stick to turn the model

Blacksmith

+Up / down steps through items; left / right changes type
AUPGRADE (the cursor waits on it)
LBRBSiris / Isa

Cauldron and Fusion Chamber

AIngredient or gem goes straight into the next empty slot; A on a filled slot takes it out
YCOOK / FUSE    X cancel / take the last gem out

Forge, brew and fusion progress

+Each slot row and its FINISH NOW; scrolls at the ends
APress

Popups and fight results

+Move the outline between the buttons
☰Yes / OK    B No / back

Gear menu

+Move through the options
APress    B close
